# 릴리(Lilly) — 숏폼/릴스 대본 기획 AI 플랫폼 🎬✨

> **"아이디어 한 줄로 3초 킬링훅부터 씬별 카메라 연출, 오디오, 자막까지 완벽하게 완성하는 바이럴 릴스 기획 파트너"**  
> 모던 바닐라 프론트엔드 컴포넌트 아키텍처 및 FastAPI SSE 스트리밍 규격을 100% 준수한 고도화된 웹 애플리케이션입니다.

## 🌟 1. 프로젝트 개요 및 기획 배경

현대 숏폼(Instagram Reels, YouTube Shorts, TikTok) 콘텐츠 시장에서는 **첫 3초 시청 유지율(Audience Retention)**, **체류 시간**, **저장(Save)/공유(Share)** 비율이 알고리즘 바이럴의 90% 이상을 결정합니다.

**릴리(Lilly)**는 단순한 범용 텍스트 생성을 넘어, 실제 크리에이터가 영상 편집 툴(CapCut, Premiere, Vrew)에서 즉시 촬영 및 편집할 수 있도록 다음과 같은 체계적인 포맷으로 실시간 기획 콘티를 도출합니다:
- **⏱️ 3초 킬링훅 (Hooking & Visual Stop):** 스크롤을 멈추게 만드는 시각·청각적 첫 씬 연출 및 화면 분할 지시
- **🎬 씬별 타임라인 구성 (Scene Breakdown):** 0~3초, 3~15초, 16~25초, 26~30초 단계별 카메라 앵글 & 시각 연출 지시
- **💬 오디오 & 나레이션 스크립트:** 성우/크리에이터 발화 톤, 효과음(SFX), 앰비언트 BGM 추천
- **🚀 바이럴 행동 유도 (Call to Action):** 시청자 댓글 토론 유도 및 캡션 저장 유도 공식

## 🎨 2. 디자인 시스템 및 UX 아키텍처 (Clean Bright Theme)

본 프로젝트는 불필요한 프레임워크 의존성 없이 순수 모던 바닐라 웹 표준(HTML5, Vanilla CSS, ES6+ JavaScript)으로 제작되었으며, 프리미엄급 시각 만족도와 부드러운 반응성을 제공합니다.

### 1) 컬러 팔레트 & 타이포그래피
- **배경 (Background):** 눈의 피로를 최소화하는 소프트 슬레이트 화이트 (`#F8FAFC`, `#FFFFFF`)
- **주 색상 (Primary):** 트렌디한 릴리 바이올렛/인디고 그라데이션 (`linear-gradient(135deg, #6366F1, #8B5CF6)`)
- **강조 색상 (Accent):** 도파민 핑크 (`#F43F5E`), 에메랄드 그린 (`#10B981`), 앰버 오렌지 (`#F59E0B`)
- **타이포그래피:** 가독성이 뛰어난 Pretendard 및 Plus Jakarta Sans를 조합한 모던 위계 시스템

### 2) 컴포넌트 부품화(Set) 구조
- **사이드바 컴포넌트 (Sidebar Set):** 
  - 릴리 인터랙티브 마스코트 아바타
  - 원클릭 '새 릴스 기획 시작' 액션
  - 동적 카운팅 배지가 포함된 기획 히스토리 스크롤 목록 (호버 액션, 개별 삭제, 전체 비우기)
  - DB 대화 로그 & 세션 추적기 모달 진입 도구
  - 크리에이터 프로필 카드 & 원클릭 게스트/로그아웃 제어
- **상단 탑바 헤더 컴포넌트 (Topbar Set):** 
  - 모바일 반응형 햄버거 토글 버튼
  - 실시간 세션 제목 및 3-Turn 문맥 유지(Context Awareness) 배지
  - **릴리 AI 실시간 상태 머신 위젯 (`IDLE` ➔ `INPUT` ➔ `PLANNING` ➔ `STREAMING` ➔ `COMPLETE`)**
  - DB 로그 팝업 바로가기, 로그인/회원가입 버튼 그룹, 프로필 위젯
- **웰컴 히어로 컴포넌트 (Welcome Hero Set):** 
  - 릴리 마스코트 캐릭터 (호버 슬레이트 모션, 무한 헤일로 회전, 눈 깜빡임)
  - **우측 지향형 말풍선 (Speech Bubble):** 상단 헤더 가림을 원천 차단하고 캐릭터 오른쪽에 꿀팁을 발화
  - 4종 카테고리별 퀵스타터 카드 (3초 꿀팁, 현실 공감 브이로그, 정보 전달 TOP 3, 알고리즘 떡상 치트키)
- **하단 입력 및 AI 컨트롤 툴바 컴포넌트 (Bottom Input Set):** 
  - 4종 원클릭 추천 훅 템플릿 가로 칩 슬라이더
  - 영상 길이(15초 초단타 / 30초 표준 / 60초 스토리텔링) 선택 셀렉트
  - 톤앤매너(바이럴 도파민 / 코믹 유머 / 신뢰 전문가 / 일상 감성) 선택 셀렉트
  - AI 마법봉 프롬프트 다듬기 버튼
  - 텍스트 자동 높이 조절(Auto-Resize) 텍스트에어리어 및 실시간 글자 수 카운터 (최대 1,000자)
  - 대본 기획 시작 및 스트리밍 즉시 중단(Abort) 전송 버튼

## ⚡ 3. 핵심 기능 명세 및 세부 디테일

### 1) 스마트 의도 분석 (Intent Classification Engine)
- 단순 인사("안녕", "반가워", "누구야", "도움말") 입력 시 억지로 릴스 대본을 생성하지 않고, 릴리의 친절한 자기소개 및 릴스 기획 프롬프트 작성 가이드를 출력합니다.
- 구체적인 영상 주제나 기획 요청 시에만 정통 릴스 기획 콘티를 생성합니다.
- 향후 실제 FastAPI 백엔드 연동 시에도 동일한 시스템 프롬프트 가이드를 적용할 수 있도록 설계되었습니다.

### 2) 실시간 SSE 스트리밍 & 동시 입력 잠금 (Concurrency Control)
- 대본 생성 중 중복 전송이나 충돌을 방지하기 위해 입력창에 `locked` 클래스가 적용되며, 반투명 블러 안내 배너가 표시됩니다.
- 전송 버튼은 붉은색 '기획 생성 중단' 버튼으로 즉각 전환되어 사용자가 언제든 생성을 안전하게 취소할 수 있습니다.
- 백엔드 미연결 환경에서도 글자 단위의 가변 타이핑(Typing Simulation) 효과로 완벽히 동작합니다.

### 3) 메인 작업 영역 기준 완벽 중앙 토스트 알림 (Anti-Spam Single Toast)
- 화면 전체(`body`)가 아닌 실제 메인 뷰포트(`app-main`)의 정중앙 하단(입력창 위 안전지대)에 단일 토스트로 렌더링됩니다.
- 2.4초 텀(쓰로틀링)을 두어 연타 시 화면을 가리는 도배 현상을 원천 차단하였습니다.

### 4) 크리에이터 인증 및 모달 시스템
- **비로그인 둘러보기:** 서비스 첫 진입 시 모달 없이 자유롭게 인터페이스 탐색 가능
- **로그인 넛지 오버레이:** 비로그인 상태에서 기획 시도 시 하단에 세련된 게이트 안내 배너 노출
- **뷰포트 정중앙 모달:** 데스크톱/태블릿 완벽 센터링, 모바일 바텀시트 전환, Safe Area 패딩 준수
- **키보드 접근성(A11y):** `ESC` 키 누름 시 모달 자동 닫기, 모달 바깥 어두운 배경(오버레이) 클릭 닫기 지원
- **비밀번호 보기/숨기기 & 실시간 강도 게이지:** 안전하고 편리한 비밀번호 입력 UX

### 5) 3-Turn 문맥 유지 (Context Awareness)
- 직전 대화 세션의 프롬프트와 기획안을 최대 3개까지 메모리에 보관하여, "방금 대본에서 톤을 더 신나게 바꿔줘" 등의 후속 피드백 지시를 완벽히 소화합니다.

### 6) SQLite / FastAPI ORM 규격 DB 로그 추적기
- 대화 세션 및 메시지별 로그 ID, 프롬프트 요약, HTTP 상태 코드(`200 OK / DB_SAVED`), 타임스탬프를 실시간으로 기록하고 팝업 모달에서 투명하게 조회 및 초기화할 수 있습니다.

## 🚀 6. 로컬 실행 방법

현재 프론트엔드는 단독 정적 웹서버로 즉시 구동 가능하며, 향후 FastAPI 백엔드가 준비되면 동일 엔드포인트로 즉시 전환됩니다.

```bash
# 1. new_front 디렉터리 진입
cd new_front

# 2. 로컬 웹 서버 실행 (8090 포트)
python3 -m http.server 8090

# 3. 브라우저 접속
http://localhost:8090
```

## 🛡️ 7. FastAPI 백엔드 연동 엔드포인트 규격

`static/js/api.js`는 표준 REST 및 SSE 스펙으로 설계되어 있습니다:
- `POST /api/auth/signup`: 회원가입 (`username`, `password`)
- `POST /api/auth/login`: 로그인 (JWT `access_token` 반환)
- `POST /api/chat/stream`: 실시간 SSE 대본 스트리밍 (`prompt`, `context`, `duration`, `tone`)
- `GET /api/me/chats`: DB에 저장된 사용자 대본 히스토리 목록 조회
- `DELETE /api/me/chats/{id}`: 특정 기획안 히스토리 삭제
