# 릴리(Lilly) — 숏폼/릴스 대본 기획 AI 플랫폼 🎬✨

> **"아이디어 한 줄로 3초 킬링훅부터 씬별 카메라 연출까지 완성하는 바이럴 릴스 기획 파트너"**  
> 모던 프론트엔드 아키텍처 및 FastAPI SSE 스트리밍 규격을 준수한 고도화된 웹 애플리케이션입니다.

---

## 🌟 1. 프로젝트 개요 및 기획 배경

현대 숏폼(Instagram Reels, YouTube Shorts, TikTok) 콘텐츠 시장에서는 **첫 3초 시청 유지율(Audience Retention)**과 **체류 시간**, **저장(Save)/공유(Share)** 비율이 알고리즘 바이럴의 90% 이상을 결정합니다.

**릴리(Lilly)**는 단순 텍스트 생성을 넘어, 실제 크리에이터가 영상 편집 툴(CapCut, Premiere)에서 즉시 촬영 및 편집할 수 있도록 다음과 같은 체계적인 포맷으로 실시간 기획안을 도출합니다:
- **⏱️ 3초 킬링훅 (Hooking):** 스크롤을 멈추게 만드는 시각·청각적 첫 씬 연출
- **🎬 씬별 타임라인 구성 (Scene Breakdown):** 0~3초, 3~10초, 10~25초, 25~30초 단계별 카메라 앵글 & 시각 연출 지시
- **💬 오디오 & 나레이션 스크립트:** 성우/크리에이터 발화 톤 및 BGM 추천
- **🚀 바이럴 CTA (Call to Action):** 댓글 토론 유도 및 저장 유도 공식

## 🎨 2. 디자인 시스템 및 UX 고도화 (Bright Clean Theme)

* **프리미엄 라이트 테마 (Modern Clean Light):**
  * 눈의 피로를 최소화하는 소프트 슬레이트 화이트(`#F8FAFC`, `#FFFFFF`) 베이스
  * 트렌디한 릴리 바이올렛/인디고(`linear-gradient(135deg, #6366F1, #8B5CF6)`) 프라이머리 컬러
  * 도파민 핑크/코랄(`#F43F5E`) 포인트 어센트
* **컴포넌트 부품화 및 모듈 설계:**
  * **사이드바 (Sidebar):** 릴리 브랜드 헤더, 새 기획 버튼, 기획 히스토리 목록(동적 카운팅 및 세션 하이라이트), DB 로그 도구, 크리에이터 프로필
  * **헤더 (Topbar):** 세션 제목, Lilly Turbo 엔진 배지, 3-turn 문맥 유지 배지, DB 로그 뷰어, 로그인/가입/로그아웃 상태 제어
  * **웰컴 히어로 (Welcome Hero):** 릴리 마스코트 캐릭터 인터랙션, 4종 카테고리별 퀵스타터 카드
  * **하단 입력 영역 (Bottom Input Floating Bar):** 원클릭 추천 템플릿 칩 슬라이더, 영상 길이(15s/30s/60s) 및 발화 톤(도파민/유머/전문가/브이로그) 선택 툴바, 프롬프트 다듬기(AI 마법봉), 텍스트에어리어 자동 높이 조절
* **릴리 마스코트 인터랙션 & 마이크로 모션:**
  * **헤일로 회전:** 10초 주기 은은한 무한 회전
  * **눈 깜빡임:** 3.8초 주기 자연스러운 눈 깜빡임
  * **슬레이트 액션:** 호버 시 찰칵하는 촬영 슬레이트 모션
  * **점프 스핀 & 발화:** 캐릭터 클릭 시 360도 스핀 점프, 머리 위 꿀팁 말풍선 툴팁 팝업, 하단 토스트 발화, 축하 색종이(Confetti) 파티클

## ⚡ 3. 핵심 기능 명세

### 1) 인증 및 상태 머신 (Auth & Gate)
- **비로그인 둘러보기:** 서비스 첫 진입 시 모달 없이 메인 화면을 자유롭게 탐색 가능
- **로그인 넛지 오버레이:** 비로그인 상태에서 질문 입력 시 하단에 안내 오버레이 노출 및 원클릭 모달 연동
- **게스트 모드:** 간편 체험을 원하는 사용자를 위한 원클릭 게스트 로그인 지원
- **회원가입/로그인 모달:** 뷰포트 정중앙 배치, 탭 전환 시 비밀번호 확인 동적 노출, 유효성 검증

### 2) 실시간 타이핑 스트리밍 (Streaming Simulation)
- FastAPI SSE(Server-Sent Events) 프로토콜 규격 100% 호환
- 실제 백엔드 연동 전에도 크리에이터의 프롬프트와 옵션(길이, 톤)을 분석하여 맞춤형 릴스 대본을 글자 단위로 실시간 타이핑 렌더링
- 생성 도중 '기획 중단' 및 '대본 재생성' 지원

### 3) 3-Turn 문맥 유지 (Context Awareness)
- 이전 대화 3개 세션을 기억하여, "방금 대본에서 톤을 더 신나게 바꿔줘" 등의 후속 피드백 대화 완벽 지원

### 4) SQLite / FastAPI ORM 규격 대화 로그 추적기
- 대화 세션 및 메시지별 ID, 역할(User/Assistant), 텍스트, 생성 시각 자동 기록
- 상단 탑바 및 사이드바에서 언제든 'DB 로그' 팝업을 열어 실시간 적재 로그 확인 및 초기화 지원

## 🚀 5. 로컬 실행 방법

현재 프론트엔드는 단독 정적 웹서버로 즉시 구동 가능하며, 향후 FastAPI 백엔드가 준비되면 동일 엔드포인트로 즉시 전환됩니다.

```bash
# 1. new_front 디렉터리 진입
cd new_front

# 2. 로컬 웹 서버 실행 (8090 포트)
python3 -m http.server 8090

# 3. 브라우저 접속
http://localhost:8090
```

## 🛡️ 6. 향후 FastAPI 백엔드 연동 규격

`static/js/api.js`는 표준 REST 및 SSE 스펙으로 설계되어 있습니다:
- `POST /api/auth/signup`: 회원가입 (`username`, `password`)
- `POST /api/auth/login`: 로그인 (JWT `access_token` 반환)
- `POST /api/chat/stream`: 실시간 SSE 대본 스트리밍 (`prompt`, `context`, `duration`, `tone`)
- `GET /api/chat/history`: DB에 저장된 사용자 대본 히스토리 목록 조회
